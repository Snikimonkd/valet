# valet, вариант A «Колода»

**Идея.** Карточная полиграфия буквально: список — колода веером, у каждой карты угловой индекс (буква магазина и масть) слева сверху и перевёрнутый справа снизу. Пропорции как у пластиковой карты. Светлая тема — лицо карты, тёмная — рубашка.

**Палитра.** Светлая: бумага #F1EADB, картон #FBF8F2, синь #1B2A47 (текст, ♠ ♣), кармин #8C2B3C (♥ ♦, ошибки), вторичный #5A6378. Тёмная: фон #10182A, карта #1A2540, текст #EFE7D6, кармин #DE8E9A, вторичный #A7AEC0. Текст везде не ниже 4.5:1. Экран QR: #FFFFFF и #000000.

**Шрифты.** Cormorant Garamond 600/700: логотип, заголовки, названия, индексы. Inter 400/500/600: интерфейс, номера с tabular-nums. Шкала Брингхерста: 12, 14, 16, 18, 21, 24, 36, 48, 60 px.

**Валет и кошелёк.** Монограмма — индекс валета «V ♥» (так валет обозначен во французской колоде, откуда пришло слово) внутри кошелька с клапаном. На входе и в пустой колоде лежит та же карта-валет.

**Почему не казино.** Нет сукна, золота, неона, фишек и тасования. Две типографские краски на бумаге, как в книжной печати; движение только в ответ на касание. Масть — метка для различения, без игровой символики.

**Компромиссы.**
- Веер прячет низ карт: номер и нижний индекс видны только у первой и последней.
- У Cormorant маленькая x-высота, поэтому мельче 21 px он не используется.
- Фиксированная высота карты и наклон через nth-child упрощают шаблон, но длинное название обрезается многоточием.
- Масти — SVG-спрайт: символы ♠♥ на части телефонов превращаются в эмодзи.
- Тёмные токены продублированы для витрины, приложению хватит media-блока.
- Удаление — dialog с showModal(): пара строк JS поверх htmx.
