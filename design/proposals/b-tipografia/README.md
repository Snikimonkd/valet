# Вариант Б «Типография»

**Идея.** Лист образцов печатни: две краски на слоновой бумаге, строгая сетка, волосяные линейки, капитель в колонтитуле, старостильные цифры в колонцифре. Единственный орнамент — угловой индекс карты: буква магазина и масть. Колода лежит каскадом, как в пасьянсе; перевёрнутый нижний индекс виден только у последней карты.

**Краски** (светлая / тёмная, выворотка):
бумага `#F3EDDF` / `#141C2E`, картон `#FBF8F1` / `#1B2539`, синька `#1D2B45` / `#EEE7D7`, разбел `#55617A` / `#A3AABA`, бордо `#7B2333` / `#D48A95`, подложка бордо `#F1E2DC` / `#2A2033`. Текст не ниже 4,5:1, границы полей не ниже 3:1.

**Шкала, px:** 12, 14, 16, 18, 24, 36, 48. Cormorant 600: имена карт 24, заголовки 36, название на входе 48; капитель колонтитула 14 с разрядкой 0,14 em. Inter 16 и 14, номера в `tabular-nums`.

**Валет и кошелёк.** Знак — индекс валета «В» с червой внутри кошелька, из кармана веером выглядывают две карты. «В» обозначает валета в русской колоде и читается как V из valet.

**Почему не казино.** Нет сукна, золота, блеска, фишек и тасовки. Масти служат типографскими значками, краски две, вместо красного приглушённое бордо, движение одно: карта приподнимается при нажатии.

**Компромиссы**
- У Cormorant мелкий глаз: имена не меньше 24 px, длинные обрезаются многоточием.
- В поставке шрифта нет smcp, капитель имитируется прописными.
- Каскад держится на фиксированной высоте карты и отрицательном отступе: в `html/template` это одна строка CSS, но высоту полосы меняют только через токены.
- Тёмные токены продублированы классом для витрины; приложению хватит `:root` и media-запроса.
- Масти нарисованы SVG-спрайтом, его нужно включить в layout.
